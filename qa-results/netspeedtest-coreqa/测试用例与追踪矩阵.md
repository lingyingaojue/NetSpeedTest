## 三、Bug 单（8 个开放缺陷）

### BUG-MTU-001　MTU 探测 TTL 硬编码为 1，跨网关目标恒失败【S3 / P2 / L3】

- **模块**：工具箱·MTU 探测　**类别**：逻辑错误　**复现**：必现
- **前置**：默认目标为海外/跨网关域名（如 speed.cloudflare.com）
- **步骤**：①打开 MTU 探测，保持默认目标；②开始探测
- **实际结果**：工具用固定 TTL=1 二分探测，包到不了第一跳之外，所有尺寸 100% 超时，最终「未找到可用 MTU」；真机 `ping -f -l 1472 -i 1` 100% 丢包、`-i 30` 正常（mtu-ttl1.txt / mtu-ttl30.txt）
- **预期结果**：先以普通 ping 验证可达、再不分片二分；TTL 应足够到达目标（如 30/系统默认）
- **根因**：Ping 工具未提供 TTL 参数，MTU 调用硬编码 TTL=1；UI 文案「最大传输单元/最大数据包」与底层「探测 ICMP 净荷、需 +28 才是链路 MTU」颠倒
- **影响**：默认跨网关目标下功能不可用；同网段网关场景可能误判
- **修复建议**：移除 TTL=1 或提供可配置 TTL（默认 30/系统默认）；先探活；文案区分 ICMP 净荷与 MTU；补「跨网关目标可达」测试
- **证据**：EVD-MTU-PING-003（L3）、源码快照　**关联**：RM-TOOL-015、TC-MTU-062

### BUG-BIDI-002　双向测速 UrlDetails 恒空、成功计数错误【S3 / P2 / L3（真机升级）】

- **模块**：测速引擎·双向　**类别**：聚合遗漏　**复现**：必现
- **步骤**：①发起双向测速；②查看结果 URL 明细/完成提示/历史详情/远程返回
- **实际结果**：`RunFullTestAsync`（SpeedTestService.cs:1794）返回 `UrlDetails = new()`；**真机双向传输 4.10GB、下载/上传速率正常，完成状态却显示「测速完成 · 0 成功」**（FinishTest 第 990 行 ok=UrlDetails 非失败数=0）
- **预期结果**：合并下载与上传两侧 UrlDetails（或分别暴露），成功计数与实际传输一致
- **根因**：双向聚合合并了速率指标但遗漏 UrlDetails 集合
- **影响**：双向模式无法定位失败节点，远程/历史缺 URL 级证据，且「0 成功」误导用户以为测速失败
- **修复建议**：聚合结果 Concat 两侧 inner.UrlDetails；成功计数基于合并集合；补 RunFullTestAsync 明细断言
- **证据**：EVD-BIDI-008（L2 源码）、**EVD-REAL-E2E-012（L3 真机「0 成功」）**　**关联**：RM-DETAIL-012、TC-NETSPEEDTEST-083

### BUG-API-SAVE-008　Web API 发起的单网卡测速结果不保存、不更新最近结果【S3 / P2 / L3，本轮新增】

- **模块**：Web 服务器·结果持久化　**类别**：状态/逻辑错误　**复现**：必现（download/upload/full 三模式均复现，repro_attempts=3）
- **前置**：启用内置 Web，经 HTTP API（而非 GUI 按钮）发起单网卡测速
- **步骤**：①GET /api/history 记录 total（实测 97）；②POST /api/test/start（download/upload/full），等待 running 归 false；③再次 GET /api/history 与 GET /api/status
- **实际结果**：三模式完成后 history.total **均不增加（97→97）**、无新记录，status.recentResult 恒空；运行日志无「SaveResult failed」（说明根本未调用保存，而非保存报错）
- **预期结果**：API 发起仅应跳过模态结果窗；SaveResult、_lastResult、RecentRecords 等持久化/最近结果更新应照常执行
- **根因**：`MainViewModel.FinishTest` 第 959 行 `if (ConsumeApiInitiatedTest()) showDialog=false;`，而第 978 行 `SaveResult` 与 979–988 行最近结果更新整体位于第 976 行 `if(showDialog){...}` 块内，API 发起时被整段跳过（本意只想跳过第 1004 行 dlg.ShowDialog 模态框）。对照多网卡 `FinishMultiNicTest` 第 1072 行 SaveResult **无条件执行**，单/多网卡行为不一致，证明系遗漏而非设计
- **影响**：手机/网页等远程发起的测速不留历史、不能导出、recentResult 恒空，远程测速无法事后复核（「远程白测」）；GUI 手动测速与实时 /api/status 速率不受影响
- **修复建议**：将 SaveResult 与最近结果更新移出 `if(showDialog)`，仅保留结果弹窗受门控；补「API 发起后 history +1、recentResult 非空」回归测试。**若产品将「远程测速留存」列为明示承诺功能，建议优先级上调至 P1**
- **规避**：临时用 GUI 手动测速（正常存档），或由 API 调用方自行记录 /api/status 速率
- **证据**：EVD-REAL-E2E-012（L4 真机三模式 total 不增）、EVD-APISAVE-SRC-014（L2 源码快照）　**关联**：RM-DATA-013、RM-LIFECYCLE-008、TC-WEB-084、BUG-BIDI-002

### BUG-CLAMP-003　设置 API 两项钳制范围与 UI/README 不一致【S3 / P2 / L2】

- **模块**：Web·设置 API　**类别**：校验不一致　**复现**：必现

### BUG-FW-006　防火墙入站规则只删不建、就绪状态恒真【S3 / P2 / L2】

- **证据**：EVD-FW-010（L2）　**关联**：RM-FW-019、TC-WEB-082

### BUG-BW-004　带宽 0 显示「∞ 秒」、负数负耗时【S4 / P3 / L2】

### BUG-SUBNET-005　不校验掩码连续性，非法掩码输出错误 CIDR【S4 / P3 / L2】

- **实际结果**：255.0.255.0 等非连续掩码未被拒绝，被当作 /16 输出网络地址/主机数
