核心特性

为重度网络用户设计的引擎

不只是跑个数字——从线程调度到结果计量，每一层都按专业标准实现。

🚀

智能测速引擎

  • 128 线程并发 HTTP GET / POST
  • URL 动态调度，实时选择最优节点
  • CPU 自适应线程上限，低配不反噬
  • 掉速紧急补偿：自动加线程 + 结果修正
  • 10s 稳定后取均值，3s 滑动窗口去毛刺
  • 200ms 渐变启动，避免瞬间占满带宽
🌐

多网卡并行测速 v1.4.0

  • 勾选多张网卡同时测速，独立绑定源 IP
  • 下载 / 上传曲线支持「合计 / 单网卡」切换
  • 双向测速显示下载 + 上传总速度
  • 完成弹窗展示每网卡独立速率与错误
  • 默认优先选中默认网关网卡
📊

NIC 级精准计量

  • 基于 IPv4Statistics 差分计算
  • 不受 HTTP 协议开销干扰
  • Kbps / Mbps / Gbps 自动切换
  • 每网卡 9 项详情信息卡
  • 独立速率条 + 活跃线程计数
🎨

专业交互体验

  • LiveCharts2 双折线图，200ms 采样、500 点窗口
  • 下载 / 上传图表可拖拽分割线
  • 模式切换 300ms 平滑过渡动画
  • 系统托盘驻留 + 气泡通知
  • GitHub Dark 暗色主题、自绘标题栏
  • 内嵌页面架构，告别弹窗
📡

全链路 UDP 优先延迟探测

  • 五层回退：UDP → ICMP → TCP 443 → HTTPS HEAD → HTTP HEAD
  • WAN / 抖动 / LAN 共用同一探测链路
  • 8.8.8.8 单主机 UDP 轮询，避免批量阻塞
  • 滑动窗口标准差算法，抖动实时平滑输出
  • 1000ms 刷新，三指标同步更新
🗄️

历史 & 配置管理

  • SQLite 持久化，独立页面 + 统计栏
  • 历史记录 CSV 导出、一键清除
  • 8 个内置 CDN 节点
  • 自定义配置导入 / 导出（JSON 兼容 HBCS）
  • 设置纯内存生效，不污染打包版默认值
